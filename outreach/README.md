# BlokesTrips Outreach Pack

Backlink outreach for: **Golf Course Etiquette Guide**
https://blokestrips.com.au/topics/golf-course-etiquette-guide-rules-tips-essentials-for-blokes/

## How to use this

1. Open `tracker.csv` — it lists every target, contact method, and requirements.
2. For each target, open the matching file in `pitches/`, copy the email, tweak
   if you like, and send it from your own address (markboydllewellyn@gmail.com
   or an @blokestrips.com.au address — the branded one converts better).
3. Update the Status / Date Sent / Link Live columns as you go.
4. When an editor says yes, they'll want the **full original article written for
   their site** — not a copy of the existing post. Come back to this session (or
   any Claude session) and ask for the draft; each pitch already defines the angle.

## Rules that keep this safe

- One natural link back to blokestrips.com.au per article. No keyword-stuffed anchors.
- Never send the same article to two sites.
- Syndication (Medium/LinkedIn) must set `rel="canonical"` to the original URL
  (Medium does this automatically when you use the Import tool).
- Space submissions out — a few per week, not twenty in a day.
- Forums and Reddit: participate genuinely; the link is incidental to a real post.

## Self-serve channels (no editor needed — do these today)

- **Google Business Profile post** linking to the article.
- **Medium**: use medium.com/p/import to import the article — canonical is set automatically.
- **LinkedIn**: publish an excerpt as an Article, link to the full guide.
- **Reddit r/golf**: see `pitches/reddit-r-golf.md` for the discussion-post approach.
